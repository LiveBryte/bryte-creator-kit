Set up your BryteMama video kit

Set up once, then bring Codex a video to get it ready to post.

Before you start

  1. Install the ChatGPT desktop app for Windows or Mac and sign in. Codex is included with ChatGPT Free and paid plans. Usage limits vary.
  2. Open Codex in the desktop app. The kit needs a local Codex chat so it can work on your computer.
  3. Start a new local chat in Codex.

Set it up

  1. Tap the button to copy your setup message.
  2. Click the chat box in Codex, paste (Ctrl+V on Windows, Cmd+V on Mac) and press Enter.
  3. Codex handles the setup. If it asks for approval, it will explain what it needs.
Hi Codex! I’m a BryteMama creator. Please set up the BryteMama Creator Kit on this computer from https://github.com/LiveBryte/bryte-creator-kit.

I’m new to Codex. Please handle the commands and keep your updates short. If you need me to click something, tell me exactly what to click.

1. Use a local chat in the desktop app with access to this computer. If the chat is remote, help me open a local chat and paste this message there.
2. Use the kit folder if it’s already open. Otherwise, retrieve the public repository into a fresh folder you can write to. You can download https://github.com/LiveBryte/bryte-creator-kit/archive/refs/heads/main.zip and extract it if Git is unavailable. I don’t need to download or unzip it myself.
3. Read the README and the installer for my operating system before running it. From the extracted kit folder, run the Windows installer with Windows PowerShell and pass -Assistant Codex, or run bash install/install.sh codex on Mac. Use the normal Codex approval flow if the installer needs internet access or permission to write to my account’s folders. Explain the approval in plain language.
4. Stay with the setup until it finishes. The first run downloads a transcription model. If a download fails, diagnose the error and retry when useful. If an approval or system prompt requires my input, walk me through it one step at a time.
5. Confirm that the installer completed successfully, that it added the BryteMama skill for Codex, and that the editor’s check command passed. Then ask me to quit and reopen the desktop app, start a new local Codex chat, and type “check my kit.” If Codex needs help finding the skill after restart, tell me to type $bryte-video check my kit.

Every video after that

  1. Start a new local chat in Codex.
  2. Drag in your video (or your voice memo and clips), or tell Codex where you saved them. Then say "make this ready to post".
  3. Your finished video lands in the BryteMama Videos folder on your Desktop.

Three kinds of videos: talking to the camera, talking over clips of your day, or quick clips you can add a sound to when you post.
