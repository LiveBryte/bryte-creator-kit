Set up your BryteMama video kit

One-time setup, about 15 minutes. After that, you drag in a video and Claude makes it ready to post.

Before you start

  1. Install the Claude desktop app from claude.ai/download and sign in. You need a paid plan (Pro or higher).
  2. Open the app and click the Code tab at the top.
  3. Start a new chat.

Set it up

  1. Tap the button to copy your setup message.
  2. Click the chat box in Claude, paste (Ctrl+V on Windows, Cmd+V on Mac) and press Enter.
  3. Claude does the rest. When it asks permission, click Allow. If Windows asks to allow changes, click Yes.
Hi Claude! Please install the BryteMama Creator Kit on this computer for me.

About me: I'm a mom, not a tech person. Keep every message short and friendly, skip the technical details, and tell me what's happening every couple of minutes. If you need me to click or type something, tell me exactly what, one step at a time.

Please handle all the commands yourself. Don't ask me to open any other app or type commands.

Here's what to do:
1. Find out if this is a Windows computer or a Mac, then download its installer and read it before running it:
   - Windows: https://raw.githubusercontent.com/LiveBryte/bryte-creator-kit/main/install/install.ps1 (run it with PowerShell: -NoProfile -ExecutionPolicy Bypass -File)
   - Mac: https://raw.githubusercontent.com/LiveBryte/bryte-creator-kit/main/install/install.sh (run it with bash)
2. It takes about 10 minutes, mostly one big download. Run it in the background and keep me posted.
3. If it stops partway, just run it again. It continues where it left off. If it keeps failing, figure out why and fix it. Only ask me if you're truly stuck.
4. Things I might need to do:
   - Windows asks "Do you want to allow this app to make changes to your device?": tell me to click Yes.
   - A Mac window asks for my password: tell me to type my computer password and click OK.
   - Claude asks permission to run something: tell me which button to click (Allow).
5. When it says DONE, finish with exactly this:

   You're all set! One last step:
   1. Quit Claude and open it again.
   2. Start a new chat.
   3. Type: check my kit

Every video after that

  1. Start a new chat in the Code tab.
  2. Drag in your video (or your voice memo and clips) and say "make this ready to post".
  3. Your finished video lands in the BryteMama Videos folder on your Desktop.

Three kinds of videos: talking to the camera, talking over clips of your day, or quick clips set to a song.
